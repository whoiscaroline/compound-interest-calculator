
# My First Finance Project

I'm learning how to use GitHub by building a simple
Python investment calculator.

## What it does

Calculates how an initial investment grows with
annual compounding.

## Example

- Initial investment: $1,000
- Annual return: 7%
- Investment period: 10 years
- Final value: approximately $1,967.15

## Files

- `calculator.py`: the Python calculator
- `README.md`: this introduction

## How to run it

Use Python 3:

python calculator.py

## Assumptions

The return stays constant, earnings are reinvested,
and there are no additional contributions, taxes, or fees.
